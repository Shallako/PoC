Renderful … Claude …

Story

Paste the story in any language. Claude segments it into ordered visual beats and writes one engine-targeted prompt per beat, plus a shared style block that keeps the set consistent. Prompts, titles and narration come back in the language you wrote in.

Engine

Parameters are validated against this schema before anything is submitted — Renderful bills a request it later rejects, so a bad value has to fail here, for free.

Shared style block

Appended to every prompt, after the scene body. Edit freely — it is re-applied to all scenes on save.

Cast

The style block holds the look; it cannot hold a face. Each character here gets one reference portrait, rendered before the scenes and passed to every scene they appear in, so they stay the same person throughout. Each portrait is one extra image on the bill. Editing a description re-renders that portrait and every scene it appears in.

Narration script

Written in the story's language. Per-scene lines are saved to text files that share the image filename, so an editor lines the pair up automatically. Review and edit here first — speaking it, below, is what costs money.

Narration audio

Speaks the script above through Renderful, on the same key that renders the images. One file per scene under the image's own name, so an editor pairs them up. Speaking a line also measures it — until then the duration beside each line is a word-count guess, and it runs long.

Render

Only scenes whose compiled prompt differs from the one stored in the manifest are re-rendered. Timestamps are ignored.

Gallery

Video

Cuts the finished video on this machine with ffmpeg: one segment per scene, held for exactly as long as its narration actually runs, joined into a single MP4. Nothing is uploaded and nothing is billed. Captions are written either way — an .srt and a .vtt land in export/ even if you never assemble a cut.

The cut

Scene lengths come from measured narration audio wherever it exists. Where a line has not been spoken yet the word-count estimate stands in, and it runs about 30% long — so the runtime below is a projection until every line has a voice.

Captions

Built from the same timeline the video is cut on, so the words on screen and the words in the ear cannot drift apart. Split at sentence boundaries, two lines at most, and timed inside each scene's own audio.

Export

Copies the selected render of each scene into export/ under flattened, sort-safe names, writes the matching narration text and audio files, and drops a copy of manifest.json beside them. Image, script and voice share one stem per scene, so dropping the folder into an editor pairs them on sight.

Provenance

One record per asset: engine, seed, params, and the exact prompt that was sent.
