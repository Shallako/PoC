Renderful … Claude …

Story

Paste the story. Claude segments it into ordered visual beats and writes one engine-targeted prompt per beat, plus a shared style block that keeps the set consistent.

Engine

Parameters are validated against this schema before anything is submitted — Renderful bills a request it later rejects, so a bad value has to fail here, for free.

Shared style block

Appended to every prompt, after the scene body. Edit freely — it is re-applied to all scenes on save.

Narration script

Script only — no synthesis. Per-scene lines are written to text files that share the image filename, so an editor lines the pair up automatically.

Render

Only scenes whose compiled prompt differs from the one stored in the manifest are re-rendered. Timestamps are ignored.

Gallery

Export

Copies the selected render of each scene into export/ under flattened, sort-safe names, writes the matching narration text files, and drops a copy of manifest.json beside them.

Provenance

One record per asset: engine, seed, params, and the exact prompt that was sent.
